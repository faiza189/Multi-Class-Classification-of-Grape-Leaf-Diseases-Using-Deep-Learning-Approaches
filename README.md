# Multi-Class Classification of Grape Leaf Diseases Using Deep Learning Approaches

A deep learning pipeline for classifying grape plant leaf images into four categories — Black Rot, ESCA (Black Measles), Leaf Blight (Isariopsis Leaf Spot), and Healthy — built and trained in Google Colab. The project compares a custom baseline CNN against several transfer learning architectures (MobileNetV2, VGG16, EfficientNetB0, ResNet50) and a hybrid CNN-VGG16 model, applies Grad-CAM interpretability, and ships a Streamlit demo app for interactive inference.

## Overview

The notebook walks through a full applied deep learning workflow:

1. **Data acquisition** — downloads the [Grapevine Disease Dataset (Original)](https://www.kaggle.com/datasets/rm1000/grape-disease-dataset-original) from Kaggle (9,027 images across 4 classes) and inspects the extracted folder structure.
2. **Exploratory Data Analysis (EDA)** — builds a DataFrame of image paths and labels, prints class distribution counts, visualizes class balance with a bar chart and pie chart, displays sample images from each class, and analyzes image width/height distributions to inform the model input size.
3. **Data splitting & augmentation** — uses `ImageDataGenerator` to split the data into 70% training / 30% validation with augmentation (rotation, shifts, flips, zoom, brightness) applied to the training set only, and visualizes a sample of augmented images to verify the pipeline.
4. **Modeling**
   - A custom baseline CNN (four convolutional blocks with batch normalization, max pooling, and fully connected layers).
   - Transfer learning with frozen pretrained backbones: **MobileNetV2**, **VGG16**, **EfficientNetB0**, and **ResNet50**, each with a custom classification head.
   - A **Hybrid CNN-VGG16** model that combines a from-scratch CNN branch with a frozen pretrained VGG16 branch.
5. **Evaluation** — training/validation accuracy and loss curves, classification reports, and confusion matrices for each model.
6. **Explainable AI** — Grad-CAM visualizations on the hybrid model's VGG16 branch to highlight the image regions driving each prediction.
7. **Model export** — saves all trained models (`cnn_model.keras`, `mobilenet_model.keras`, `vgg16_model.keras`, `hybrid_model.keras`) plus a class-index config file to `saved_models/`, and packages them into a downloadable zip.
8. **Deployment demo** — a Streamlit app (`app.py`, generated from the notebook) that loads all four saved models and serves predictions, exposed publicly from Colab via a Cloudflare tunnel.

## Dataset

- Source: [Grapevine Disease Dataset (Original) on Kaggle](https://www.kaggle.com/datasets/rm1000/grape-disease-dataset-original) (`rm1000/grape-disease-dataset-original`)
- 9,027 grape leaf images across 4 classes: `Black Rot`, `ESCA (Black Measles)`, `Leaf Blight (Isariopsis Leaf Spot)`, `Healthy`

## Setup & Usage

1. **Kaggle API credentials**: obtain a `kaggle.json` API token from your Kaggle account settings and have it ready to upload when prompted by the notebook.
2. Open the notebook in Google Colab and run the cells in order:
   - Upload `kaggle.json` when prompted, which configures the Kaggle CLI.
   - The dataset is downloaded and extracted automatically.
   - Run the EDA cells to explore class distribution, sample images, and image dimensions.
   - Run the data splitting/augmentation and modeling sections sequentially to train the baseline CNN, MobileNetV2, VGG16, EfficientNetB0, ResNet50, and hybrid models.
3. **Training**: all models train on GPU if available (falls back to CPU otherwise, which will be slow).
4. **Explainable AI**: run the Grad-CAM cells to visualize which regions of an image drive the hybrid model's predictions.
5. **Model weights**: trained models are saved under `saved_models/` and can be downloaded as a zip archive.
6. **Streamlit demo**: the final cells install Streamlit and Cloudflared, write out `app.py`, launch it on port `8501`, and expose a public URL via a Cloudflare tunnel.
